# Contributing

Fixes, new features, new boards and new housings are all welcome.

## Sending a change

1. Fork the repository on GitHub and make your change on a branch of your fork.
2. Check it as described in [Checking a change](README.md#checking-a-change): build every platform it touches, with no warnings.  For a housing, render it and, if you can, print it and check it fits.
3. Update the documentation that goes with it: the feature's page in [`docs/features/`](../features/), the board's page, or the housing's README.
4. Open a pull request against `master`.  Say what the change does, why, and which boards you've tried it on.

For a bigger change, like a new feature or a new board, it's worth opening an issue first to talk it over, so the work fits with the rest of the project.
