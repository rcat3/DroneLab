> BEFORE YOU START

  • Use Chrome or Edge on a computer (Windows, macOS, Linux or a Chromebook). Other browsers, and phones, can't reach USB devices.
  • Use a USB-C cable that carries data. Many charging cables don't.
  • The unit can stay in its housing: the USB-C port is on its right side (under its cover, if you printed one).
This browser can't reach USB devices. Open this page in Chrome or Edge on a computer. The page has to be opened over https to reach USB devices.

Takes about a minute. Don't unplug the unit until it says it's done.

> INSTALLATION PROTOCOL

  1. Plug the unit into the computer.
  2. Press Install DroneLab, and pick the unit from the list: it's called USB JTAG/serial debug unit, or something with ttyACM, usbmodem or COM in it.
  3. On a new unit, tick Erase device when it asks. To update a unit, leave it unticked, and its settings are kept.
  4. When it's done, the unit restarts with the DroneLab logo. Continue with First Start.

> IF IT DOESN'T WORK

  • The unit isn't in the list: try another cable or USB port. If it still isn't, unplug it, hold the BOOT button (the upper one on its left side) while plugging it back in, and try again. Afterwards, press PWR or unplug it and plug it back in to start it.
  • On Linux, it can't open the port: add yourself to the dialout group, then log out and back in.
  • To flash by hand instead, download DroneLab-firmware-1.75.bin from the latest release and see Installing the Firmware.
