## Asset Files Explained
**Companion App:** 
  - **Android**: Open the downloaded file and allow your browser or Files app to install unknown apps.  See [Installing a release](https://github.com/rcat3/DroneLab/blob/master/docs/app/installing.md#installing-a-release) for more information.
      - **_For most Android phones:_** [`DroneLab.apk`](https://github.com/rcat3/DroneLab/releases/download/@TAG@/DroneLab.apk)
      - **_For older 32-bit Android phones:_** [`DroneLab-armv7.apk`](https://github.com/rcat3/DroneLab/releases/download/@TAG@/DroneLab-armv7.apk). 
  - **Linux:**  See [On a Linux computer.](https://github.com/rcat3/DroneLab/blob/master/docs/app/installing.md#on-a-linux-computer) for more information.
    - **_For a PC:_** [`DroneLab-linux-x64.tar.gz`](https://github.com/rcat3/DroneLab/releases/download/@TAG@/DroneLab-linux-x64.tar.gz) 
    - **_For Raspberry Pi 4 or 5:_** [`DroneLab-linux-arm64.tar.gz`](https://github.com/rcat3/DroneLab/releases/download/@TAG@/DroneLab-linux-arm64.tar.gz)  
     
For general information on using the app, see the [app guide](https://github.com/rcat3/DroneLab/blob/master/docs/app/README.md).


**Firmware:** Display unit firmware is included with the companion app.  If your display unit has been programmed at least once, the app will give you the option of upgrading the firmware over the Bluetooth wireless connection.  Alternatively, you can install the firmware from your browser with the [web installer](https://rcat3.github.io/DroneLab/).  If none of these options work for you, flash [`DroneLab-firmware-1.75.bin`](https://github.com/rcat3/DroneLab/releases/download/@TAG@/DroneLab-firmware-1.75.bin) by hand (see [Installing the Firmware](https://github.com/rcat3/DroneLab/blob/master/docs/building-firmware.md)).

**3D Printable parts:** Ready to print STL files.  Print them yourself or send them to a print service. See the [Build Guide](https://github.com/rcat3/DroneLab/blob/master/docs/build/README.md) for more information.
  - **_Speaker Enclosure:_** [`DroneLab-speaker-model-stl.zip`](https://github.com/rcat3/DroneLab/releases/download/@TAG@/DroneLab-speaker-model-stl.zip)
  - **_Low Profile Enclosure:_** [`DroneLab-low-profile-model-stl.zip`](https://github.com/rcat3/DroneLab/releases/download/@TAG@/DroneLab-low-profile-model-stl.zip)
